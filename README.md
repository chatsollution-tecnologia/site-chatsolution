# Site ChatSolution

Site institucional publicado pelo GitHub Pages em https://chatsollution.com

- `src.html` — o site (edite aqui).
- `assets/` — logos (normal, branca e ícone).
- `build.py` — gera o `index.html` final com as logos embutidas: `python3 build.py`
- `index.html` — arquivo publicado (gerado, não editar à mão).
- `CNAME` — domínio do site. Não apagar.

Para mudar o site: peça ao Claude no projeto "PAINEL - CHATSOLLUTION". Ele edita e envia para cá; o site atualiza em 1–2 minutos.
